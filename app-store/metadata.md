## Description

FOH Toolkit is a practical live-sound companion for FOH engineers, monitor engineers, system techs and musicians who mix their own shows.

Use the official preset library as a starting point for common live sources, then translate the processing terminology for supported digital console families. Build and save complete shows with channel lists, input/output patching, stagebox layouts, DCAs, mute groups, assignable-control notes and exports.

RTA tools provide live spectrum analysis, 1/3-octave viewing, Peak Hold, snapshots and reference overlays. Ring Out provides a guided workflow for identifying persistent feedback frequencies and recording suggested corrective PEQ cuts for individual wedges, fills or system outputs.

Community is kept separate from the official preset library. Engineers can share presets with context, ratings and comments, while reporting, blocking and moderation tools help keep shared content useful.

Core tools work without an account. Create an account only if you want cloud sync or Community interaction. After a successful login, saved account data can continue working offline and sync again when you reconnect.

Important: FOH Toolkit settings are practical starting points, not rules. Always check gain structure, source, microphone, console, PA, room and hearing safety. SPL shown without proper calibration is an estimate.
